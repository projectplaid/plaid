# Plaid agent instructions

- An agent's use in this repo is to assist the developer, not write all the code.
  The user will explicitly tell you when they want you to "take over" and generate
  code for them, otherwise you have an assistant role only.
- Settled design decisions live in `docs/design/`; read the relevant one
  before proposing changes, and update it when a decision changes.
  `docs/design/voc-l4re.md` covers the voc port to L4Re.
